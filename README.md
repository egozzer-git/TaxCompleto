# Latino Tax Service

Sitio web estático bilingüe para Latino Tax Service — Enrique Gozzer, EA. White Plains, NY.

## Ver localmente
Abre `index.html` en tu navegador.

## Publicar en GitHub Pages
1. Crea repo público llamado `TaxCompleto`.
2. Sube todos los archivos.
3. Settings → Pages → Source: main → / (root) → Save.
